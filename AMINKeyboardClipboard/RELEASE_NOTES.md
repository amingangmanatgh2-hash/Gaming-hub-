# AMIN Keyboard & Clipboard — 1.0.0

کیبورد مجازی فارسی/انگلیسی + تاریخچه متنی کلیپ‌بورد برای ویندوز ۱۰ (1803 و جدیدتر).

## 📦 فایل‌های این نسخه

| فایل | توضیح |
|---|---|
| `AMINKeyboardClipboardSetup.exe` | نصب‌کننده (Inno Setup 6) — نصب per-user، بدون UAC، رابط فارسی/انگلیسی |
| `AMINKeyboardClipboard-portable.zip` | نسخه بدون نصب؛ فایل zip را باز کنید و `AMIN Keyboard Clipboard.exe` را اجرا کنید |
| `SHA256SUMS.txt` | چک‌سام SHA-256 هر دو فایل بالا |

## ⚙️ پیش‌نیاز

- ویندوز ۱۰ نسخه 1803 (build 17134) یا جدیدتر / ویندوز ۱۱
- **.NET Framework 4.8** — نصب‌کننده وجود آن را بررسی می‌کند؛ اگر نبود از [اینجا](https://dotnet.microsoft.com/download/dotnet-framework/net48) نصب کنید.
- دسترسی Administrator لازم **نیست**.

## ✨ چه چیزی در این نسخه هست

- کیبورد شناور فارسی/انگلیسی با ارسال یونیکد (`SendInput`) — مستقل از لی‌آوت کیبورد ویندوز.
- پنجره کیبورد فوکوس پنجره مقصد را نمی‌دزدد (`WS_EX_NOACTIVATE`)؛ با کشیدن نوار عنوان جابه‌جا می‌شود و محلش ذخیره می‌شود.
- تاریخچه متنی کلیپ‌بورد: حداکثر ۱۰۰ مورد، حذف تکراری، جستجو، کپی مجدد، حذف، پاک‌سازی کامل.
- ذخیره محلی در `%LocalAppData%\AMINKeyboardClipboard\` — بدون هیچ اتصال شبکه‌ای.
- میانبر سراسری: تلاش برای `Win + V` و در صورت اشغال بودن، `Ctrl + Alt + V` (در تب تنظیمات نشان داده می‌شود).
- اجرای خودکار اختیاری در ورود به ویندوز (فقط `HKCU`، بدون UAC).
- اجرای تک‌نمونه‌ای + پنجره خوش‌آمد و توضیح حریم خصوصی.

## 🔬 این بیلد چگونه ساخته شده و چه چیزی تست نشده

این فایل‌ها خروجی خودکار GitHub Actions هستند (`.github/workflows/build-windows.yml`):
`dotnet build` روی `windows-latest` با .NET Framework 4.8، سپس کامپایل اسکریپت Inno Setup 6.
یعنی **سورس کامپایل می‌شود** و نصب‌کننده بدون خطا ساخته می‌شود — همین.

موارد زیر **تست نشده‌اند** و صادقانه نمی‌توانیم بگوییم تأیید شده‌اند:

1. اجرای برنامه روی سخت‌افزار واقعی، مخصوصاً **Dell Latitude با Windows 10 1803**.
2. رفتار تایپ در Word / مرورگر / برنامه‌های خاص (کنترل‌های غیراستاندارد ممکن است ورودی Unicode را نپذیرند).
3. پنجره‌های Elevated (Administrator): ویندوز جلوی تزریق ورودی از برنامه معمولی را می‌گیرد (UIPI)؛ برنامه پیام راهنما نشان می‌دهد.
4. در دسترس بودن `Win + V` روی هر سیستم (ویندوز معمولاً آن را برای Clipboard History گرفته است).
5. اجرای نصب‌کننده روی همان دستگاه 1803.

## ⚠️ نکات

- بیلد **امضای دیجیتال ندارد**؛ SmartScreen ممکن است هشدار «Windows protected your PC» بدهد → `More info` → `Run anyway`.
- تاریخچه **رمزنگاری نمی‌شود** و فقط متن است (نه تصویر، نه فایل، نه گذرواژه). اگر رایانه مشترک است، از «حذف کامل داده‌های محلی» استفاده کنید.
- بستن پنجره اصلی = خروج کامل برنامه (این نسخه آیکن سینی ندارد).
- تاریخچه در `%LocalAppData%\AMINKeyboardClipboard\` باقی می‌ماند و با حذف برنامه پاک نمی‌شود.
