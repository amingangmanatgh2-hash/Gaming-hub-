# ShadowCore BW Shader — Lightweight BedWars Optimized

This is the bundled lightweight shader included with ShadowCore 1.1.

- **Goal:** Bright, beautiful, high-contrast but very fast (30-60 FPS on low-end)
- **BW Optimizations:**
  - No heavy shadow sampling — sun shadows at 0.5x resolution, 1 sample
  - Bright caves (Fullbright-like but via shader, not XRay) — see enemies in dark corners
  - Cyan-tinted light matching ShadowCore theme, warm bed highlights
  - Optimized fog for BedWars maps (short fog, clear view of bridges)

**Install:**
1. Install Iris + Sodium (Modrinth)
2. The mod auto-copies this shader to `shaderpacks/ShadowCore_BW.zip` on first launch if Iris is present
3. In-game: Options > Video Settings > Shader Packs > ShadowCore_BW

Alternatively, for best visuals download **Complementary Shaders** or **Sildur's Vibrant Lite** (free) and drop into shaderpacks/.
