# ShadowCore Features — Deep Dive

## FPS Optimizer

- **Entity Culling:** Mixin on `EntityRenderer.shouldRender` — cancels rendering if `squaredDistance > cullingDistance²`. Excludes player & vehicle. Saves ~15-30% GPU on entity-heavy servers.
- **Particle Limiter:** Mixin on `ParticleManager.addParticle` — counts per-tick, drops overflow beyond `maxParticlesPerTick` (default 64). Configurable; respects `fpsOptimizerEnabled`.
- **Smart Render Distance:** Optional. Samples FPS for 1s, adjusts `options.viewDistance` ±1 to keep FPS near `targetFps`. Disabled by default to avoid surprising users.

## Better Sprint

Vanilla-like sprint lock. No velocity modification. Future: could add toggle keybind via `KeyBindingHelper`.

## AutoTool

Scores each hotbar slot by `stack.getMiningSpeedMultiplier(state)`. Skips tools below durability threshold. Prefers correct tool. Triggered only while `attackKey.isPressed()` and crosshair hits block.

## Inventory Sorter

Collects stacks 9-35, sorts by comparator (TYPE/NAME/QUANTITY), reinserts. Called via `ModuleButton` click. Uses `player.inventory.setStack` for immediacy; multiplayer sync via next inventory tick.

## Fullbright (legit)

Sets `options.gamma` to 12.0 on enable, restores `previousGamma` on disable. No shader/block transparency. This is identical to editing `options.txt` gamma manually — allowed everywhere.

## Zoom

Tracks `ZoomModule.ZoomState.multiplier` lerped each tick. Future mixin can apply to `GameRenderer.getFov`. Currently exposed for HUD/other consumers; simplest FOV: multiply camera FOV in render tick.

## Waypoints

- Stored in `ShadowCoreConfig.waypoints` as `WaypointEntry` list.
- `WaypointManager` handles add/remove/clear + persistence.
- `WaypointRenderer` draws beacon beam (DEBUG_LINES) + label placeholder. Full label uses `TextRenderer` + billboard; current version draws beam + distance in command feedback.
- Dimension-aware: only renders if `dimension == currentDim`.

## Minimap

- HUD panel top-right, `minimapSize` square.
- Samples top non-air block per pixel via `world.getBlockState` + `getMapColor`.
- Modulates brightness by height delta for depth cue.
- Player dot + yaw needle. No caves, no entities (unless `minimapShowEntities=true`).

## HUD

Top-left overlay: FPS, XYZ, direction, biome (registry key pretty-printed), MC time + IRL time. Respects `hudHidden`. Background 66% black for contrast.

## ClickGUI

- `ClickGuiScreen` — Screen with semi-transparent backdrop.
- `CategoryPanel` — per `ModuleCategory`, header with accent stripe, draggable, front-bring on click.
- `ModuleButton` — row with enabled dot, hover tint, toggle action. Special case for sorter (also sorts).

## Keybinds & Commands

- Right Shift, C, B, M registered via `KeyBindingHelper`.
- `/shadowcore` via `ClientCommandRegistrationCallback` — fully client-side, no server command conflict.

## Config

Gson pretty JSON in `config/shadowcore.json`. Loaded at `onInitializeClient`, saved on toggle/change. No Cloth Config dependency to keep jar small; adding Mod Menu integration is trivial (add `modmenu` entrypoint).

## Mixins

`shadowcore.mixins.json` refs `client` mixins. All client-only, required=true. `refmap` generated by Loom.
