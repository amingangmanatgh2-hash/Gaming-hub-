# راهنمای نصب و استفاده — AMIN Keyboard & Clipboard

**منیجرِ کلیپ‌بورد و صفحه‌کلید بیانیهٔ فارسی/انگلیسی برای ویندوز ۱۰**

---

## ۱. پیش‌نیازها

- ویندوز ۱۰ (نسخه ۱۸۰۳ یا جدیدتر)
- [ویژوال استدیو ۲۰۲۲ Community](https://visualstudio.microsoft.com/vs/visual-studio-desktop/) (رایگان)
- هنگام نصب، حتماً کارلاود **«.NET desktop development»** را فعال کنید (سرمایِ شامل **.NET Framework 4.8** است).

## ۲. ساخت برنامه (Build)

1. همین صفحه‌ی ریپازیتوری را دانلود/کپی کنید.
2. پوشه‌ی `AMIN_Keyboard_Clipboard` را باز کنید.
3. فایل `AMIN_Keyboard_Clipboard.sln` را دوبار کلیک کنید.
4. منوی **Build → Configuration** را روی **Release** بگذارید، سپس **Build Solution** (یا کلید F6) را بزنید.
5. اگر خطای قرمز گرفتید، دقیقاً همان پیام را در یکپارچه‌سازی بگذارید.

## ۳. اجرای برنامه

- F5 را بزنید یا از **Debug → Start Without Debugging** استفاده کنید.
- برنامه پنجره‌ی اصلی را باز می‌کند.

## ۴. صفحه‌کلید بیانی (Virtual Keyboard)

- از تب **Virtual Keyboard** یا دکمهٔ **Show Floating Keyboard** استفاده کنید.
- کلیدهای فارسی (بر اساس معیار **ISIRI**) و انگلیسی (QWERTY) را کلیک کنید؛ کاراکتر در **برنامه‌ی فعال** تایپ می‌شود.
- دکمهٔ **⇧ (Shift)** برای حروف انگلیسی بزرگ‌نویسی می‌کند.
- دکمهٔ **FA / EN** برای تغییر زبان.
- دکمهٔ **ZWNJ** (نیم‌فاصله، U+200C) برای پیوستن کلمات فارسی.
- پنجره‌ی کیبورد همیشه‌ی رویه (Always on Top) است و focus را از برنامه‌ی شما نمی‌گیرد.

## ۵. منیجر کلیپ‌بورد (Clipboard Manager)

- تب **Clipboard Manager**: تاریخچه تا ۱۰۰ مورد با ذخیره‌سازی JSON.
- کلیک روی هر مورد → کپی به کلیپ‌بورد ویندوز.
- جست‌وجو (search)، حذف و پاک‌کردن تاریخچه.
- ذخیره در: `%APPDATA%\AMIN_Keyboard_Clipboard\history.json` (پس از restart restoration)

## ۶. اختصارات جهانی (Hotkeys)

| کمبین | کاربرد |
|---|---|
| `Ctrl+Alt+K` | نمایش/مخفی پنجره‌ی کیبورد |
| `Ctrl+Alt+V` | نمایش/مخفی پنجره‌ی منیجر کلیپ‌بورد |

> `Win+V` (اختصار تاریخچه‌ی ویندوز) با این برنامه تداخل ندارد.

## ۷. شروع همراه با ویندوز

- تب **Settings** → tick **«Start AMIN with Windows»**
- یا دکمهٔ **Start with Windows** در پایین پنجره.
- shortcat در پوشه‌ی Startup ویندوز ساخته می‌شود (نیاز به admin ندارد).

## ۸. نصب نهایی (Installer)

1. [Inno Setup 6](https://jrsoftware.org/isinfo.php) را نصب کنید.
2. اسکریپت `installer/AMIN_Keyboard_Clipboard.iss` را با ISCC compile کنید.
3. نصب‌کننده‌ی exe تولید می‌شود.

## ۹. ساختِ خودکار با GitHub Actions

- workflow `build-windows.yml` در ریپازیتوری: روی windows-latest msbuild اجرا می‌کند، exe را zip می‌کند و (اختیاری) نصب‌کننده‌ی Inno Setup می‌سازد — artifact قابل دانلود است.

## ۱۰. حریم خصوصی و محدودیت‌ها

- **فقط متن**: عکس و فایل پشتیبانی نمی‌شود (مطابق با درخواست).
- شکل‌دهی (shaping) فارسی وابسته به موتورمتن اپ می‌باشد؛ در ویراتورهای استاندارد (Notepad، Word، مرورگرها) مشکلی نیست.
- **هیچ telemetry و upload وجود ندارد** — همه‌چیز محلی.
- نیاز به admin ندارد.
