# AMIN Keyboard & Clipboard 1.1.0 — نسخه بومی ویندوز (بدون .NET)

> **این نسخه دیگر به .NET Framework نیاز ندارد.** برنامه یک فایل اجرایی بومی Win32 است
> (C، لینک استاتیک با CRT). ویندوز برای اجرای آن هیچ چیزی لازم نیست نصب کند.
> اگر نسخه قبلی روی کامپیوتر شما با پیام «.NET Framework 4.8.1 پشتیبانی نمی‌شود» نصب نمی‌شد،
> این نسخه مشکل را برطرف می‌کند.

## 📦 فایل‌های این نسخه

| فایل | توضیح |
|---|---|
| `AMINKeyboardClipboardSetup.exe` | نصب‌کننده — نسخه ۶۴ یا ۳۲ بیتی را خودکار انتخاب می‌کند، per-user، بدون UAC |
| `AMINKeyboardClipboard-win64.zip` | نسخه بدون نصب برای ویندوز ۶۴ بیتی |
| `AMINKeyboardClipboard-win32.zip` | نسخه بدون نصب برای ویندوز ۳۲ بیتی |
| `SHA256SUMS.txt` | چک‌سام SHA-256 همه فایل‌ها |

## ⚙️ پیش‌نیاز

- ویندوز ۷ SP1 یا جدیدتر (شامل Windows 10 نسخه 1803) — ۶۴ یا ۳۲ بیتی
- **هیچ چیز دیگری**: نه .NET Framework، نه Visual C++ Redistributable، نه رانتایم.
  CRT به‌صورت استاتیک داخل فایل اجرایی لینک شده است.

## ✨ قابلیت‌ها

- **کیبورد فارسی/انگلیسی شناور** با ارسال یونیکد (`SendInput`)، مستقل از لی‌آوت ویندوز.
- پنجره کیبورد با `WS_EX_NOACTIVATE` ساخته می‌شود: کلیک روی کلیدها فوکوس پنجره مقصد را نمی‌دزدد.
- پنجره کیبورد با کشیدن نوار عنوان جابه‌جا می‌شود و محلش ذخیره می‌شود (روی مانیتورهای دیگر هم بررسی می‌شود).
- **تاریخچه متنی کلیپ‌بورد**: حداکثر ۱۰۰ مورد، یکتا، جستجو، کپی مجدد، حذف، پاک‌سازی کامل.
- ذخیره محلی در `%LocalAppData%\AMINKeyboardClipboard\` — هیچ اتصال شبکه‌ای وجود ندارد.
- میانبر سراسری: تلاش برای `Win + V`، در صورت اشغال بودن `Ctrl + Alt + V` (در تب تنظیمات نمایش داده می‌شود).
- اجرای خودکار اختیاری در ورود به ویندوز (فقط `HKCU`، بدون UAC).
- آیکن سینی: بستن پنجره برنامه را نمی‌بندد؛ به سینی می‌رود تا میانبر فعال بماند. خروج از منوی آیکن.
- اجرای تک‌نمونه‌ای (اجرای دوم، پنجره موجود را باز می‌کند).
- پنجره خوش‌آمد و توضیح حریم خصوصی در اجرای اول.

## 🔒 حریم خصوصی

- فقط `CF_UNICODETEXT` خوانده می‌شود؛ تصویر، فایل و هر قالب دیگری نادیده گرفته می‌شود.
- هیچ کد شبکه‌ای در برنامه نیست (نه آمار، نه آپلود، نه به‌روزرسانی خودکار).
- هیچ تشخیص یا ذخیره گذرواژه‌ای وجود ندارد.
- فایل‌ها: `clipboard-history.dat` (دودویی، رمزنگاری‌نشده)، `settings.ini`، `first-run.done`.
- تاریخچه **رمزنگاری نمی‌شود**. روی رایانه مشترک از «حذف کامل داده‌های محلی» استفاده کنید.

## 🔬 این بیلد چگونه ساخته شده و چه چیزی تست نشده

این فایل‌ها خروجی خودکار GitHub Actions هستند: کامپایل با MSVC (`cl`, `/MT`) برای x64 و x86،
سپس کامپایل اسکریپت Inno Setup 6. یعنی **کد کامپایل و لینک می‌شود** و وابستگی‌های فایل اجرایی
فقط DLLهای خود ویندوز است (`dumpbin /dependents` در لاگ بیلد موجود است).

**تست نشده:**

1. اجرای برنامه روی سخت‌افزار واقعی — از جمله Dell Latitude با Windows 10 1803.
2. رفتار تایپ در Word / مرورگر / کنترل‌های غیراستاندارد.
3. پنجره‌های Administrator (محدودیت UIPI ویندوز؛ برنامه پیام راهنما نشان می‌دهد).
4. در دسترس بودن `Win + V` روی هر سیستم.
5. اجرای نصب‌کننده روی همان دستگاه.

## ⚠️ نکات

- بیلد **امضای دیجیتال ندارد**؛ SmartScreen ممکن است هشدار بدهد → `More info` → `Run anyway`.
- اگر برنامه قبلی (نسخه .NET) نصب است، اول آن را حذف کنید؛ `AppId` نصب‌کننده یکی است و
  نصب‌کننده جدید جایگزین نسخه قبلی می‌شود.
- بستن پنجره = رفتن به سینی. برای خروج کامل: راست‌کلیک روی آیکن سینی → «خروج».

## 🧾 تغییرات نسبت به نسخه ۱.۰.۰ (WPF/.NET)

- کل برنامه به C/Win32 بازنویسی شد → **بدون نیاز به .NET Framework** (دلیل اصلی این نسخه).
- نصب‌کننده بدون بررسی .NET و بدون هیچ پیش‌نیاز رانتایم.
- آیکن سینی و رفتار «بستن = ماندن در سینی» اضافه شد.
- کیبورد شناور کاملاً بومی: بدون فوکوس‌ربایی، با کشیدن دستی و ذخیره محل.
- ذخیره‌سازی تاریخچه به فرمت دودویی کوتاه با نوشتن اتمیک تغییر کرد.
