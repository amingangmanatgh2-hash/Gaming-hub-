# ارائهٔ درس ۳ مطالعات اجتماعی پایه هفتم

## نسخهٔ ۷ کنفرانس سینمایی (نسخهٔ پیشنهادی)

`output/چرا_به_قانون_نیاز_داریم_نسخه_۷_کنفرانس_سینمایی.pptx`

نسخهٔ ۷ یک ارائهٔ ۱۸ اسلایدی برای کلاس و کنفرانس است. اسلاید ۲ فهرست فصل‌بندی‌شدهٔ کتاب‌مانند دارد. طراحی بر پایهٔ تایپوگرافی درشت، پنل‌های شیشه‌ای چندلایه، کنتراست مناسب و تصویرهای سه‌بعدی شکل گرفته است. حرکت اصلی فقط بین اسلایدها اتفاق می‌افتد: ۱۳ Morph هدفمند با اشیای هم‌نام، دو Zoom، دو Split و یک Wipe؛ بدون صدا، GIF یا انیمیشن داخلی سنگین.

### تقسیم ارائه

- امین کریم‌پور: اسلایدهای ۱، ۲، ۳ و ۱۸
- عزیزی: اسلایدهای ۴ تا ۷
- طاها عابدی‌فر: اسلایدهای ۸ تا ۱۱
- گله‌دار: اسلایدهای ۱۲ تا ۱۴
- محمدرضا فولادی: اسلایدهای ۱۵ تا ۱۷

متن کوتاه و جداگانهٔ نسخهٔ ۷ برای هر عضو:

`output/متن_اعضا_نسخه_۷/`

## نسخهٔ ۶

فایل نسخهٔ ۶ و متن‌های همان نسخه برای مقایسه در `output` و `output/متن_اعضا/` باقی مانده‌اند. نسخه‌های ۱ تا ۴ نیز در پوشهٔ `output` موجودند؛ نسخهٔ ۵ طبق درخواست قبلی حذف شده است.
