# ارائهٔ درس ۳ مطالعات اجتماعی پایه هفتم

## نسخهٔ ۵ کنفرانس گروهی (جدیدترین نسخه)

`output/چرا_به_قانون_نیاز_داریم_نسخه_۵_کنفرانس_گروهی_۱۸_اسلاید.pptx`

نسخهٔ ۵ هویت رنگی پنج ارائه‌دهنده را به نوار پایین هر اسلاید اضافه می‌کند و زمان ارائه را دقیقاً برای حدود ۱۰ دقیقه تنظیم کرده است. فایل‌های همراه شامل راهنمای کامل تقسیم نقش، متن پیشنهادی هر اسلاید، لحن، مکث، زبان بدن، جمله‌های تحویل بین اعضا و برنامهٔ اضطراری هستند:

- `output/راهنمای_تقسیم_نقش_و_متن_ارائه_نسخه۵.pdf`
- `output/راهنمای_تقسیم_نقش_و_متن_ارائه_نسخه۵.docx`

## نسخهٔ ۴ شاهکار کنفرانسی (پیشنهادی)

`output/چرا_به_قانون_نیاز_داریم_نسخه_۴_شاهکار_۱۸_اسلاید.pptx`

نسخهٔ ۴ پس از بررسی حدود ۱۰۰ نتیجه و منبع آموزش طراحی ارائه بازطراحی شده است: ۱۸ اسلاید برای کنفرانس حدود ۱۰ دقیقه، تایپوگرافی درشت، حاشیه و فاصله‌گذاری حرفه‌ای، چهار خانوادهٔ چیدمان متفاوت، شش تصویر سه‌بعدی، Morph هدفمند و ترنزیشن‌های داستان‌محور. این نسخه هیچ GIF یا فایل صوتی ندارد و فقط ۳٫۷ مگابایت است تا روی رایانهٔ مدرسه روان اجرا شود.

راهنمای اجرای اسلایدبه‌اسلاید: `راهنمای_ارائه_نسخه۴.md`

## نسخهٔ ۳ سینمایی (جدیدترین نسخه)

`output/چرا_به_قانون_نیاز_داریم_نسخه_۳_سینمایی_۳۶_اسلاید.pptx`

نسخهٔ ۳ شامل ۳۶ اسلاید، بیش از ۷۰ مگابایت محتوای باکیفیت، ۶ صحنهٔ سه‌بعدی سینمایی، ۳۶ پس‌زمینهٔ اختصاصی، ۴۵ دارایی تصویری، افکت‌های HUD متحرک، چهار نوع صدای ویژه، آزمایشگاه تصویری رانندگی، شبیه‌سازی اردو، مناظره و بازی کلاسی است.
