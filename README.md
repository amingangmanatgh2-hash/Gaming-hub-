# 🤖 Self-Bot Hub — ربات تلگرامی سلف‌ساز + پنل مدیریت وب

سیستم کامل «سلف‌ساز تلگرام» با اقتصاد الماس 💎، پنل شیشه‌ای داخل تلگرام (`@helperlevibot`)،
پنل مدیریت وب برای مالک و کرون نگهداری روزانه — **قابل دیپلوی روی Cloudflare Workers + KV / D1**.

---

## 🚀 لینک دیپلوی (مهم‌ترین بخش!)

### روش ۱ — دکمه دیپلوی مستقیم روی کلادفلر (یک‌کلیکی)

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/amingangmanatgh2-hash/Gaming-hub-)

```
https://deploy.workers.cloudflare.com/?url=https://github.com/amingangmanatgh2-hash/Gaming-hub-
```

> با کلیک روی این لینک، کلادفلر مخزن را کلون کرده، فضای KV را می‌سازد و Worker را
> روی آدرس `https://self-bot-hub.<your-subdomain>.workers.dev` دیپلوی می‌کند.
> ⚠️ این دکمه از شاخه پیش‌فرض (main) می‌خواند — پس از merge شدن این شاخه فعال است.

### روش ۲ — دیپلوی با Wrangler CLI (۴ دستور)

```bash
npm i -g wrangler
wrangler login

# 1) ساخت KV و کپی id داخل wrangler.toml
wrangler kv namespace create SELFBOT_KV

# 2) (اختیاری) ساخت D1 + اسکیما
wrangler d1 create selfbot-db
wrangler d1 execute selfbot-db --file=./schema.sql

# 3) دیپلوی
wrangler deploy
```

خروجی دیپلوی، آدرس نهایی شما است: `https://self-bot-hub.<subdomain>.workers.dev` ✅

### پس از دیپلوی — راه‌اندازی ۳۰ ثانیه‌ای

1. آدرس Worker را در مرورگر باز کنید → **فرم راه‌اندازی زیبا** نمایش داده می‌شود.
2. توکن ربات (از `@BotFather`) + آیدی عددی مالک (از `@userinfobot`) را وارد کنید.
3. سیستم به‌صورت خودکار: توکن را با `getMe` اعتبارسنجی → در KV امن ذخیره → **وب‌هوک تلگرام را ست می‌کند** → کلید مدیریت پنل وب را به شما می‌دهد (و برای مالک در تلگرام هم ارسال می‌شود).
4. پنل مدیریت وب: `https://<worker-url>/panel`

## 📂 ساختار پروژه

| فایل | توضیح |
|---|---|
| `worker.js` | کل سیستم: وب‌هوک تلگرام، موتور دستورات ماژولار، اقتصاد الماس، API و Frontend تعبیه‌شده |
| `wrangler.toml` | پیکربندی Cloudflare (KV ،D1 اختیاری، Cron Trigger روزانه) |
| `schema.sql` | اسکیمای اختیاری D1 (آینه کاربران + لاگ تراکنش الماس) |
| `frontend/setup.html` | نسخه مستقل فرم راه‌اندازی (همان که در Worker تعبیه شده) |
| `frontend/panel.html` | نسخه مستقل پنل مدیریت وب |
| `dev-server.js` | شبیه‌ساز محلی Workers (KV در حافظه) برای پیش‌نمایش — `npm run dev` |

## ⚠️ نکته فنی

Cloudflare Workers فقط به **Bot API** تلگرام دسترسی دارد (نه MTProto)؛ بنابراین «سلف» این سیستم
روی زیرساخت Bot API پیاده شده و قابلیت‌هایی مثل تغییر واقعی نام/بیو اکانت شخصی به‌صورت
شبیه‌سازی/صف پردازش ارائه می‌شوند. استفاده از سلف واقعی MTProto خلاف قوانین تلگرام است.
