# چرا به قانون نیاز داریم؟ — نسخهٔ نهایی

فایل آمادهٔ ارائه:

`output/چرا_به_قانون_نیاز_داریم_نسخه_نهایی.pptx`

## مشخصات
- ۱۸ اسلاید فارسی و RTL برای ارائهٔ حدود ۱۰ دقیقه
- تم تاریک مدرن با طلایی، آبی و فیروزه‌ای
- متن کوتاه و قابل بیان؛ بدون پاراگراف‌های طولانی
- تصاویر سه‌بعدی باکیفیت و فشرده
- چهار نمونهٔ GIF کوچک و ظریف در نقاط کلیدی
- پنج صدای کوتاه در شروع فصل‌ها و پایان
- جابه‌جایی اسلاید فقط با کلیک؛ هیچ زمان‌بندی خودکاری وجود ندارد
- حجم فایل حدود ۲٫۱۴ مگابایت

## تقسیم ارائه
- امین کریم‌پور: اسلایدهای ۱، ۲، ۳ و ۱۸
- عزیزی: اسلایدهای ۴ تا ۷
- طاها عابدی‌فر: اسلایدهای ۸ تا ۱۱
