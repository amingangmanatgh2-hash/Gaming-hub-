# ارائهٔ درس ۳ مطالعات اجتماعی پایه هفتم

فایل نهایی ارائه در مسیر زیر قرار دارد:

`output/چرا_به_قانون_نیاز_داریم_گروه۶.pptx`

این پاورپوینت ۱۶ اسلاید فارسی و راست‌به‌چپ دارد و شامل طراحی سینمایی تیره، کارت‌های شیشه‌ای، نمودارها و المان‌های برجسته، شماره‌گذاری اسلاید، ترنزیشن خودکار/کلیکی و افکت‌های صوتی ملایم است.

برای بازسازی فایل:

```bash
python -m venv .venv
.venv/bin/pip install python-pptx Pillow lxml
.venv/bin/python create_presentation.py
```
