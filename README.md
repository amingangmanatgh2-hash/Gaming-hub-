# ارائهٔ درس ۳ مطالعات اجتماعی پایه هفتم

## نسخهٔ ۳ سینمایی (جدیدترین نسخه)

`output/چرا_به_قانون_نیاز_داریم_نسخه_۳_سینمایی_۳۶_اسلاید.pptx`

نسخهٔ ۳ شامل ۳۶ اسلاید، بیش از ۷۰ مگابایت محتوای باکیفیت، ۶ صحنهٔ سه‌بعدی سینمایی، ۳۶ پس‌زمینهٔ اختصاصی، ۴۵ دارایی تصویری، افکت‌های HUD متحرک، چهار نوع صدای ویژه، آزمایشگاه تصویری رانندگی، شبیه‌سازی اردو، مناظره و بازی کلاسی است.

## نسخهٔ سینمایی ۳۰ اسلایدی

نسخهٔ جدید شامل ۳۰ اسلاید فارسی و راست‌به‌چپ، بیش از ۵۴ مگابایت محتوای تصویری باکیفیت، رندرهای سه‌بعدی سینمایی، ۳۰ پس‌زمینهٔ اختصاصی، HUD متحرک، کارت‌های شیشه‌ای، ترنزیشن خودکار/کلیکی و چهار نوع افکت صوتی ویژه است.
