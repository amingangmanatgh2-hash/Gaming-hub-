## About `preview/`

These PNGs are generated by `tools/render_preview.py`, which parses
`src/core/layout.cpp` and `src/win/amin.h` directly and re-implements
`core::compute_row()` and the dashboard's `compute_layout()` one-to-one.
They exist to inspect the layout without a Windows machine.

They are **approximations, not screenshots**: the real program draws with GDI and
shapes Persian with Uniscribe using Tahoma, while the previewer uses Pillow with
Vazirmatn. They were used during development to catch two real bugs (a row that
did not sum to 15 key-units, and an overlapping privacy note in the clipboard tab).

Regenerate with:

```bash
python3 -m pip install pillow arabic-reshaper python-bidi
python3 tools/render_preview.py            # writes docs/preview/*.png
```
