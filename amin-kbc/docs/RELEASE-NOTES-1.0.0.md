# AMIN Keyboard & Clipboard — نسخه Native (بدون .NET) — 1.0.0

کیبورد مجازی فارسی/انگلیسی + تاریخچه کلیپ‌بورد متنی برای **ویندوز ۱۰ (از جمله ۱۸۰۳) و ویندوز ۷ SP1 به بالا**.

این نسخه با **C++17 و Win32 خالص** ساخته شده و **به هیچ Runtime یا .NET نیاز ندارد** —
فقط یک فایل اجرایی. مناسب Dell Latitude E5570 با ۸ گیگابایت رم.

## 📦 فایل‌های این نسخه

| فایل | توضیح |
|---|---|
| `AMIN-Keyboard-Clipboard-1.0.0.zip` | **پیشنهادی**: هر دو نسخه + نصاب + راهنمای فارسی + مستندات |
| `AminKeyboardClipboard-x64.exe` | نسخه ۶۴ بیتی (پرتابل، بدون نصب) — ۶۲۴ کیلوبایت |
| `AminKeyboardClipboard-x86.exe` | نسخه ۳۲ بیتی (برای ویندوز ۳۲ بیتی) — ۶۵۱ کیلوبایت |
| `SHA256SUMS.txt` | چک‌سام SHA-256 هر سه فایل |

## ⚙️ پیش‌نیازها

- ویندوز ۱۰ (build 17134 / 1803 یا جدیدتر) یا ویندوز ۷ SP1 / ۸.۱ / ۱۱
- **هیچ چیز دیگری لازم نیست**: نه .NET، نه Visual C++ Redistributable، نه دسترسی Administrator
- فقط DLLهای خود ویندوز استفاده می‌شوند (Kernel32/User32/GDI32/Shell32/Ole32/Advapi32/Comctl32/Usp10)

> ⚠️ این Release را با `kb-v1.0.0` اشتباه نگیرید: آن یکی نسخه **WPF/.NET Framework 4.8** است
> و برای اجرا به نصب .NET 4.8 نیاز دارد. نسخه حاضر Native است.

## 🚀 شروع سریع

1. فایل ZIP را دانلود و کامل استخراج کنید (یا فقط یکی از exeها را بردارید).
2. روی `AminKeyboardClipboard-x64.exe` دوبار کلیک کنید.
   اگر SmartScreen پیام داد → `More info` → `Run anyway` (فایل امضای دیجیتال ندارد).
3. در جادوگر اولیه، میان‌بر کلیپ‌بورد را انتخاب کنید.
4. برای تایپ: ابتدا روی کادر متن برنامه مقصد کلیک کنید، بعد «نمایش صفحه کلید» را بزنید.
5. نصب اختیاری بدون دسترسی مدیر: `install.bat` (یا `install.bat /autostart`).

## ✅ وضعیت تست (صادقانه)

**تأیید شده در محیط ساخت:**
- ۶۴۸ بررسی خودکار منطق برنامه (متن فارسی/UTF-8، JSON، تاریخچه، تنظیمات، میان‌برها، چیدمان هر ۲۰ ردیف کلید)
- همین مجموعه زیر AddressSanitizer + UndefinedBehaviorSanitizer → بدون خطا
- فازینگ: ۶۰٬۰۰۰ ورودی تصادفی (JSON، UTF-16، بدترین حالت) → بدون کرش
- کامپایل هر دو معماری با `-Wall -Wextra` → صفر اخطار
- بازرسی PE: زیرسیستم GUI، حداقل نسخه ویندوز ۶.۰، منابع (آیکون/نسخه/manifest)، **عدم استفاده از هیچ API مربوط به ویندوز ۸+ یا ۱۰ نسخه‌های جدید**، بدون کد شبکه

**تأیید نشده (چون محیط ساخت ویندوز نبود):** اجرای واقعی رابط گرافیکی، تزریق کلید به برنامه دیگر،
ثبت کلید میان‌بر، آیکون سینی، ساخت میان‌بر، و اجرای اسکریپت‌های نصاب.
برای همین، برنامه یک خودآزمایی دارد که همه این‌ها را روی رایانه شما واقعاً امتحان می‌کند:

```
AminKeyboardClipboard.exe --selftest
```

گزارش در `%APPDATA%\AminKeyboardClipboard\selftest.log` ذخیره می‌شود (PASS/FAIL/SKIP برای هر مورد).

## 🔒 حریم خصوصی

- فقط **متن** ذخیره می‌شود؛ تصویر و فایل هرگز.
- **هیچ کد شبکه‌ای** وجود ندارد (به هیچ DLL شبکه‌ای لینک نشده است).
- داده‌ها در `%APPDATA%\AminKeyboardClipboard` می‌مانند؛ اجرای خودکار فقط در `HKCU`.
- تشخیص خودکار رمز عبور وجود ندارد؛ هنگام کار با اطلاعات حساس «توقف ثبت» را بزنید.
